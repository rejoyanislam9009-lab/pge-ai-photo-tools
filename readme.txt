API-free smart photo tools with command-based local processing, passport presets, styles, batch downloads, and a printable CV builder.

== Description ==
Use [pge_ai] to add a front-end photo processor. No API key is required. Imagick is preferred; GD is supported as a fallback.

This is local image processing rather than generative AI. It does not synthesize missing face details or replace clothing.

== Installation ==
1. Upload and activate the plugin.
2. Add [pge_ai] to a page.
3. Configure Settings > PGE Photo Tools if needed.
